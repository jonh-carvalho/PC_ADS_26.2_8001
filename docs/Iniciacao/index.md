# Iniciação

> Objetivo: Definir o escopo inicial do projeto e alinhar os objetivos principais.

## Principais atividades:

* Definição do escopo do projeto

* Visão geral da solução

* Análise de viabilidade

* Identificação de riscos iniciais

* Identificar os principais requisitos alto nível (funcionais e não funcionais).

* Estimar custos e prazos iniciais.

### Artefatos:

* Documento de Visão

* Lista de Riscos Iniciais

* Casos de Uso Principais.

* Criar um caso de negócio (business case).
